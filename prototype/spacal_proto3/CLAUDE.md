# CLAUDE.md — prototype/spacal_proto3 (agent rules; AGENTS.md links here)

sPHENIX 2017 SPACAL prototype (Prototype3, W/SciFi, 2D-projective) ported from sPHENIX's
`PHG4SpacalPrototypeDetector.cc` to GEMC Perl generators, plus the `solid_spacal` hit process in
`../../source/2.9/hitprocess/`. Human-facing overview: `readme`. Design: `SPACAL_PLAN.md`. History: `log.md`.
Numbers: `result.md`. Everything runs inside the solid_gemc container (jlabce 2.5, GEMC 2.9) from this directory.

## Files

| File | Role |

| `fiber_layout_ref.py` | oracle: Python port of the sPHENIX fiber code -> `ref_fibers_<var>.txt` (not committed) |
| `geo_check.py`, `fiber_clearance.py` | independent transform cross-check (and geantino aiming), analytic fiber overlap check |
| `check_hitprocess.py <run>` | hit process vs GEMC integrated raw info (gcard INTEGRATEDRAW=solid_spacal, evio2root `-R=solid_spacal`) |

## Regenerate and validate (in the container, from this directory)

The container shell is tcsh: set variables with `env VAR=... cmd`, not `VAR=... cmd`.
```
python3 sphenix_xml2param.py sphenix_ref/cemc_geoparams-0-0-4294967295-1483238881.xml solid_spacal_proto3
foreach v (mini nofiber Original)
  ./solid_spacal.pl solid_spacal_proto3 $v
end
python3 fiber_layout_ref.py solid_spacal_proto3__parameters_mini.txt > ref_fibers_mini.txt
python3 fiber_layout_ref.py solid_spacal_proto3__parameters_Original.txt > ref_fibers_Original.txt
# host (needs numpy): python3 geo_check.py solid_spacal_proto3 Original;  python3 fiber_clearance.py solid_spacal_proto3 Original
# hit process, only if the maps or the model changed
root -l -b -q export_lightmaps.C;  root -l -b -q test_spacal_model.C
cd ../../source/2.9 && scons OPT=1 -j4 && cd -
env EVIO_OPTS="-B=$PWD/solid_spacal_proto3 -R=solid_spacal" ./run.sh spacal_proto3_p2_e1GeV_raw.gcard <id>
# host (needs numpy, uproot): python3 check_hitprocess.py runs/<id>
```
Regenerated text files must be byte-identical to the committed ones unless the generators changed.
The container has Python 3.6 without numpy: `sphenix_xml2param.py`, `fiber_layout_ref.py`, `make_scan.py` run in the container;
`geo_check.py`, `fiber_clearance.py`, `check_hitprocess.py`, `analyze_*.py` run on the host (numpy, uproot, matplotlib).

## Conventions and traps (verified in GEMC 2.9 source or by test)

- Sensitive = fiber core (`_core<j>`, hit type `solid_spacal`). Core identifier `CH ncopy 0` reads the clad copy number =
  fiber code `100000*(sector+1) + 10000*tower + fid`; the hit process outputs `id` = channel `10000 + 1000*sector + 100*tower + 10*subx + suby`.
- GCards need `HIT_PROCESS_LIST=solid`, `PHYSICS=FTFP_BERT+STD` (without `+STD` there is no EM physics) and
  `PRODUCTIONCUT=0.7` (GEMC's default is 10 mm). Parallel jobs need distinct `-RANDOM=<seed>`.
- Sectors and towers are not `CopyOf` (a copy shares daughters, so fiber codes would repeat). Only clads are `CopyOf _CHa<j>`.
- Name tokens `CH`, `SEC`, `TWR`, `LG` must each occur at one hierarchy level only (`ncopy` takes the outermost name match).
- Originals sort before copies (`CHa` < `CHb`); GEMC builds volumes alphabetically.
- Rotation: GEMC "a b c" -> M = Rz Ry Rx used as a frame (passive) rotation; active Rx(t) -> "-t 0 0". Verified by the geantino tests.
- Tower G4Trap pDx4 is replaced by the planar value (Geant4 10.7 aborts otherwise); fibers keep the XML numbers.
- No strings in `__parameters` files (GEMC's TEXT parameter factory evaluates every value as a number).
- Model constants in `__parameters`: `spacal_birks_kB` (0.07943 mm/MeV, Geant4 10.7 G4_POLYSTYRENE), `spacal_time_min/max` (0/60 ns).
- Geantinos take one step through a core (the step limit does not act on them): their hit position is the exit point.
- Known limitations: neutral-particle deposits not Birks-quenched; the sPHENIX fiber-transmission map (Prototype2Module.xml) covers
  +-6.75 cm while Prototype3 fibers reach +-8.2 cm (clamped, as in sPHENIX).
